# Tame Impala, a fan-made concept site

An unofficial redesign of tameimpala.com, made by a fan. Not affiliated with Tame Impala or Sony Music.
Ticket, music, store and news links all go to the official sources.

Plain HTML, CSS and JS with GSAP. Open `index.html` through any static server, for example:

    python -m http.server 5173
